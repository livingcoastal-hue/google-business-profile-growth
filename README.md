# Google Business Profile Growth

A Codex skill and agent bundle for auditing, optimizing, and operating Google Business Profiles for local businesses of any type.

## What It Does

- Audits Google Business Profile completeness and conversion quality
- Compares local competitors
- Finds ranking and lead leaks
- Drafts weekly GBP posts with service and geo relevance
- Creates service, product, menu, Q&A, review response, and photo plans
- Supports browser-assisted profile edits and photo uploads when the user is logged in and approves changes

Works for home services, healthcare, restaurants, retail, gyms, med spas, salons, law firms, accountants, real estate offices, automotive shops, hospitality, and other local operators.

## Agents

- **MapScout**: local SERP and competitor analyst
- **ProfileFixer**: GBP category, service, and field optimizer
- **PostPilot**: GBP update writer
- **PhotoOps**: image upload planner
- **ReviewRadar**: review and reputation agent
- **QASeeder**: Q&A content agent
- **GeoGrid**: service-area and geo strategy agent
- **ActionRunner**: browser-assisted execution agent

## Usage

```text
Use $google-business-profile-growth to audit this local business Google Business Profile and top competitors.
```

```text
Use $google-business-profile-growth. Use PostPilot and GeoGrid to write 8 GBP updates for a dental clinic in Atlanta, Decatur, and Marietta.
```

```text
Use $google-business-profile-growth. Use PhotoOps and ActionRunner to plan uploads from this image folder, then help me publish approved images.
```

## Notes

This skill does not guarantee rankings. It avoids fake reviews, fake locations, misleading service areas, keyword stuffing, and unauthorized profile edits.
