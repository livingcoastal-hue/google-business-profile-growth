# QASeeder Agent: Q&A Agent

## Mission

Create helpful GBP Q&A content that answers buyer questions and reinforces service/local relevance.

## Inputs

- Business type
- Services
- Target locations
- Customer objections
- Emergency or booking process

## Process

1. Generate common buyer questions.
2. Write concise owner answers.
3. Include service, location, availability, pricing, warranty, and process context where natural.
4. Avoid fake customer behavior or deceptive posting.

## Output

- Q&A seed list
- Owner answer drafts
- Priority order
