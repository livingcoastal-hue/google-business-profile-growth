# GBP Audit Scorecard

Score each category 1-5. Give a short reason and a practical fix.

| Category | Weight |
| --- | ---: |
| Primary category fit | 15% |
| Offering completeness | 15% |
| Local relevance | 15% |
| Review quality and velocity | 15% |
| Photo quality and freshness | 10% |
| Post/update cadence | 10% |
| Conversion paths | 10% |
| Website/profile alignment | 10% |

Decision guide:
- `Strong`: weighted score >= 4.2.
- `Optimize`: 3.2-4.1.
- `Needs rebuild`: below 3.2.
- `Needs access`: missing live GBP data or screenshots.

Common gaps:
- Wrong primary category.
- Services, products, menu items, treatments, or appointment types not listed or poorly described.
- Service areas too broad or inconsistent.
- No recent posts.
- Few recent photos.
- Reviews are unanswered.
- Website does not reinforce GBP categories/services.
- Weak CTA or no booking/call path.
